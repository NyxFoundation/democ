# assets

デモをまたいで使い回す素材を貯めるところ。デモ 1 本のための文言とコードは
`demos/<名前>.yaml` に書くので、ここに置くのは「複数のデモで同じものを出す」ものだけ。

| 場所 | 中身 |
|---|---|
| `snippets/` | 何度も出すコード片。YAML から貼って使う |

デモ 1 本のための台本・切り方・3D の組み方は `demos/<名前>/` に入る。ここに置くのは
複数のデモで同じものを出すときだけ。

画像や動画をここに置いてもよいが、生成できるものは生成する側に寄せる。`out/` と同じ
ものを `assets/` に置かない。
