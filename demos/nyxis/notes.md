# nyxis — 訴求動画の注記

`demos/nyxis.yaml` が本体。ここには、YAML を読んでも分からないこと——画面に出る数字の
出どころ、言い切りの線引き、どこまでが実物でどこからが概形か——だけを書く。

127 秒。認可バグ → レビューが見落とす理由 → 書くのはポリシーだけ →
ポリシーが項になり、定理に代入され、カーネルが木を降りて型を合わせる → 失敗の形 →
出てくるバイナリ → 締め。概念図は 1 枚も出てこない。

## 冒頭の数字の出どころ

OWASP Top 10:2021 の A01 Broken Access Control。34 CWE がマップされ、occurrence
318,487 件、CVE 19,013 件、テストされたアプリの 94% に何らかの形で存在。1 位（前回
5 位から上昇）。<https://top10.owasp.org/2021/A01_2021-Broken_Access_Control>

これが動画の中で唯一の外部データなので、版を更新するときは出典を取り直すこと。

## 移植は 1 回にする

コードが飛ぶ画面を 2 回出していた時期がある。1 回目は Cedar がパースされて Lean の値に
なる、2 回目はその値が定理の ∀ に代入される。原理的には別だが、絵がほぼ同じなので
繰り返しに見える。

いまは 1 回。着地した右パネルに `def sources := ⟨…⟩` と
`theorem authorization_safety := Nyxis.Approved.authorization_safety sources …` を続けて
置き、1 枚で「値になる」と「定理に渡る」の両方を見せている。流れは cedar → lean →
lake build → lake exe の一本。

## 公理は最初から葉に置く

木を育てたあとに公理を出して「依存の末端はこの 3 つの公理」と説明していた時期がある。
いまは木と同時に葉として出して、説明を省いている。残るのは三つ。依存を辿って型が
一致すれば証明は正しい（全ノード緑）。一致しなければ不備（`≠` の例）。それをビルドが
機械的に判定する（`✓ 型検査 ok` → バイナリ）。

## 文言について

二度直している。一度目は比喩を落とし、二度目は「決め台詞」を落とした。

比喩をやめた例。「そのまま Lean の項に化けて埋まる」→「Lean の値になり、証明済みの
定理に渡される」。「877 件にぶら下がった木になっている」→「877 件の定義と補題に
依存している」。「節がひとつ合わないだけで、木ごと落ちる」→「一箇所でも型が合わな
ければ、ビルドは失敗する」。

決め台詞をやめた例。「2 人が読んで、2 人とも通した」→「このコードはレビューを通って
いる」。「書くのはポリシーだけ。ハンドラは AI に任せていい」→「開発者が書くのは、
Cedar のスキーマとポリシー」。「403 を判断したコードは、このファイルにない」→
「readPost は callAction を呼ぶだけで、認可を判断していない」。

対句・体言止め・短い断定を並べたくなったら、たいてい AI 臭が出ている。説明の文に
戻すこと。

## 正直さの線

Lean が言うのは「ポリシーが正しいか」ではなく範囲の話。締めの
「承認したポリシーが許す範囲を超える操作は、発行されない」は強めないこと。
ビルドが落ちる例は `scripts/check-schema-rejection.sh` が実際に検査している挙動。

## 中身の出どころ

依存の木の名前、241 / 636、公理 3 つ、`nyxis_approved` の挙動、ビルドのエラー文言、
`lean_exe` の出力先は `Nyxis/Runtime.lean`、`Nyxis/Build.lean`、`Nyxis/Approved.lean`、
`Main.lean`、`lakefile.lean`、`scripts/check-schema-rejection.sh` の実物。

第 2 層・第 3 層の枝の張り方は見せるための概形で、実際の依存の形そのままではない。
`server.js` は典型的な IDOR で nyxis のコードではない。人物名・ファイル名・
`app.example.com`・ビルド時間は作り物。

## 短くするなら

掴み用に落とすなら、この順で削る。

1. `ハンドラ` の場面（`BulletinBoard/Handlers.lean` のカード）
2. 型検査の「合わなかった場合」（`inspect` の 2 つめ。ただし緑の意味づけが半分になる）
3. `tree` の `error`（失敗の形を先に見せる一区画）
4. `labels` の文を短くする。保持時間は文字数から決まるので、秒ではなく文を削る

移植の 1 枚と、1 ノードを開く区画は削らないこと。ここが答えになっている。
