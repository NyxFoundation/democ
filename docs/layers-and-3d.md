# 画面を 3D に持ち込む

HTML で作った画面を、部品ごとの透過 PNG に切り出して、Blender の空間に板として
並べる。UI はモデリングしない。平面の絵として扱い、カメラのほうを動かす。

これで HTML が原理的に出せないものが付く。被写界深度、モーションブラー、実光源が
縁を拾う反射、そしてフレームの正確さ。逆に、文字の組版と「あとから文言を直せる」
性質は HTML 側に残る。文言を直したらレイヤーを撮り直すだけで、`.blend` の中の
アニメーションはそのまま生きる。

```sh
make layers     # demos の画面 → out/layers/<名前>/*.png
make 3d         # → out/3d/<名前>.blend と out/3d/<名前>.mp4
```

## 層に分ける

1 枚の絵にしてしまうと、あとは全体をスライドさせることしかできない。部品ごとに
分けておくと Z 方向にずらせるので、視差が出て、片方だけにピントを置けて、別々に
動かせる。インタラクティブに見えるのはここ。

切り出し方は `layers/<デモ>/<ショット>.yaml` に書く。置き場所から行き先
（`out/<デモ>/layers/<ショット>/`）が決まるので、仕様に書くのは中身だけでよい。

```yaml
scene: 7                      # demos の何番目のシーンか
clear: [".sc", ".stage", ".stage-wrap"]   # 透明にするために背景を消すもの
layers:
  - name: left
    select: "#sp .l"
    js: "D.cls('#sp','on'); D.html('#spL', s.left.codeHtml.join('\n'));"
```

どのレイヤーも、再生させて秒で狙うのではなく `js` で状態を作る。シーンの `hold` を
変えた途端に別の絵が撮れてしまうのを避けるため。`js` の中では `s` がそのシーンの
仕様（`DEMO.scenes[scene]`）を指す。再生した途中を撮りたいときだけ `play: true` と
`at:`（秒）を書く。

`scale: 2` を書くと、板のテクスチャが 2 倍の細かさで撮れる。カメラが寄る場面では
これがないと文字がにじむ。`layers.json` は CSS px のままなので、3D 側の配置は変わらない。

`element.screenshot` は要素の矩形をそのまま撮るので、**重なっている別の要素も写る**。
板の文字が箱に写り込むようなら、撮る前に邪魔なものを空にする。

書き出し先には `layers.json` も出る。どの部品が画面のどこにあったかが入っていて、
Blender 側はこれを見て板を並べる。

## 3D 側

`assets/3d/<ショット>.py` と `layers/<デモ>/<ショット>.yaml` が対になる。`split.py` が実例。

画面座標はそのまま持ち込む。1600x1000 px を 16x10 単位として扱い、カメラをちょうど
その幅が収まる距離に置く。あとはその基準からずらしていく。**1 単位 = 100 px**に
しているのは、現実寸法に近づけないと物理カメラの被写界深度が破綻するため。
1 単位 = 1000 px で組むと、F 値をいくつにしても全部ボケる。

カメラの回転は手で打たない。注視点の Empty を置いて `TRACK_TO` で追わせる。寄りと
手打ちのパンは必ず喧嘩して、被写体が画面から外れる。

## 踏んだ穴

板を X 軸に 90° 回したあと、**高さは local Y**。`scale = (w, 1, h)` と書くと高さが
常に 1 になる。`(w, h, 1)` が正しい。

Blender 4.4 で Action が slot 制になり `action.fcurves` が無くなった。`split.py` の
`fcurves()` が両方を見ている。

EEVEE は `--background` でも動く（Blender 5.2.3 / Intel UHD で確認）。ただし
モーションブラーを入れるとフレームあたり数秒かかる。

## タイムラインへの入り方

`layers/<デモ>/<ショット>.yaml` の `scene:` は、切り出し元であると同時に「この 3D カットが
どのシーンを置き換えるか」の宣言でもある。`edit/timeline.py` がこれを見て、
`out/<デモ>/screens/07-移植.mp4` の代わりに `out/<デモ>/3d/<ショット>.mp4` を並べる。
前後には 0.25 秒の溶かしが入る。絵の質が変わる継ぎ目はそのほうが落ち着く。

3D は 1 フレーム数秒かかるので、`make` の既定経路では焼き直さない。`make 3d` を
通したあとに `make` すれば取り込まれる。

## 渡すもの

クリエイタに渡すのは mp4 ではなく **`out/<デモ>/3d/<ショット>.blend`**。
開けば板・カメラ・ライト・キーが全部そこにあり、続きが作れる。mp4 は確認用。
